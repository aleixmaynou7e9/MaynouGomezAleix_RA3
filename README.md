# Winter Madness

**Winter Madness** és un joc de plataformes en el qual canvies la gravetat del personatge per avançar en els nivells ambientats en una muntanya nevada.

## Controls

- **`A` / `D`**: Moviment cap a l'esquerra i la dreta respectivament.
- **`Space`**: Canviar la gravetat del jugador (*Player*).
- **`Esc`**: Pausar el joc.
